# HealthInformatics

An end-to-end data engineering project built on the [Fitbit Fitness Tracker dataset](https://www.kaggle.com/datasets/arashnic/fitbit). It covers data ingestion, profiling and cleaning, relational storage, cloud warehousing, containerized deployment, and automated testing.

## Reproduction Steps

### 1. Obtain the Dataset

1. Download the dataset from [Kaggle](https://www.kaggle.com/datasets/arashnic/fitbit).
2. Extract the downloaded ZIP archive. Note the path of the extracted `fitbit/` folder; it is referred to below as `{dataset_folder}`.

### 2. Clone the Repository

```bash
git clone https://github.com/bnogh123/HealthInformatics.git
cd HealthInformatics
```

### 3. Ingest the Dataset

Run the ingestion script, replacing `{dataset_folder}` with the path to your local `fitbit/` folder:

```bash
python Scripts/Localized_Ingestion.py {dataset_folder}
```

Upon completion, an `ingested_data/` directory containing the processed source files will exist in the repository root.

### 4. Clean the Dataset

```bash
python Scripts/EDA.py clean
```

### 5. Run Exploratory Data Analysis

After cleaning is complete, run the profiling routines (record counts, schema documentation, and null analysis):

```bash
python Scripts/EDA.py eda
```
